# ¡Trabajo Sí Hay!

Plataforma web de empleos de barrio en la localidad de Bosa en Bogotá D.C (con la visión de llegar a otras localidades). Conecta a los negocios que necesitan personal con personas que buscan trabajo cerca de su casa.

## Páginas

- **Inicio:** hero con acceso a las vacantes.
- **Vacantes:** tarjetas generadas con JavaScript desde un arreglo de objetos.
- **Publicar vacante:** formulario que guarda la vacante en sessionStorage.
- **Nosotros:** quiénes somos y por qué nació el proyecto.

## Tecnologías
- HTML
- CSS: mobile first, media queries, variables, flexbox y grid
- JavaScript: arreglo de objetos, for...of, innerHTML, addEventListener y sessionStorage
- Git y GitHub Pages
