# ¡Trabajo Sí Hay !

Plataforma wed de empleos de barrio en la Localidad de Bosa en Bogotá D.C (con Vision de proyeccyión de alcance a otras localidades y seguir aumentando su alcance). Conecta a los negocios que necesitan personal con personas que buscan trabajo cerca de su casa.

## Páginas

- **Inicio:** hero con acceso a las vacantes.
- **Vacantes:** tarjetas generadas con JavaScript desde un arreglo de objetos.
- **Publicar vacante:** formulario que guarda la vacante en sessionStorage.
- **Nosotros:** quienes somos y por qué nació el proyecto.

## Tecnologías
-HTML
-CSS: mobile first, media queries, variables, flexbox y grid
-JavaScript: arreglo de objetos, for...of, innerHTML, addEverListener y sessionStorage
-Git y GitHub Pages
